# Personal Cinema

## 観た映画の記録が、そのまま<br>「自分の紹介文」になるアプリ

Team Skynet / Supabase × Devin Hackathon

<!--
15秒。名乗り＋一行だけ。中身の説明はしない。

## 困っていること：記録しても、自分のことは分からない

- 記録アプリに星をつけても、残るのは**作品ごとの点数**だけ
- 配信サービスのおすすめは出るけれど、**なぜ勧められたのか分からない**
- だから、たくさん観ている人でも**「好きな映画は？」に一言で答えられない**

> 記録は増えるのに、自分の説明は増えない。

35秒。3点を1文ずつ。最後の一行を強めに言い切る。

## 誰のためのアプリか

- 月に 2〜3 本は映画を観る人
- 感想は書かないけれど、**観たものは残しておきたい**人
- 点数で競うのではなく、**趣味が合う人と話したい**人

**欲しいのは検索窓ではなく、自分を映す鏡。**

## いま使われているものを 3 つ並べると

| よく使われているもの | できること | 足りないこと |
| --- | --- | --- |
| 映画の記録アプリ<br>（Filmarks / Letterboxd） | 観た作品と点数を残す | **自分の好みは言葉にならない** |
| 配信サービスのおすすめ<br>（「一致度 96%」の表示） | 次に観る作品を出す | **理由が出ない・記録は残らない** |
| 16 タイプの性格診断 | 自分を一言で説明できる | **一度やったら終わり** |

**この 3 つを 1 つにまとめたのが、私たちのアプリです。**

<!--
35秒。既存例を実名で出して立ち位置を先に示す。ここで聞き手の地図が揃う。
-->

<!-- _footer: '1:45 – 2:25（40秒）' -->

## やることは、星をつけるだけ

| やること | 起きること |
| --- | --- |
| 星をつける | 好みが少しずつ記録される |
| 数本たまる | **自分のタイプ**と**好みを表す図**が現れる |
| さらに評価 | タイプも図も**その場で変わる** |
| 棚に並べる | 観た映画が**自分の本棚**になる |

**アンケートも設定もいりません。入力は星ひとつだけ。**

<!--
40秒。ここが一番大事。「記録アプリと同じ操作しかしない」と言い切る。
-->

## 好みを「8 つの言葉」に置き換える

**情緒 / 思考 / 没入 / 物語 / 映像美 / 疾走感 / 未知 / 余韻**

- 星をつけると、その映画が持つ要素があなたの好みに足される
- 低く評価した映画の要素は、**逆に「苦手」として記録される**
- 音楽アプリの年間まとめと同じ発想で、**足し算だけで人物像を作る**

## 結果には、診断のような名前がつく

- 例：**「世界の設計図を読む人」**／**「余韻の中に住む人」**（全 16 種類）
- 性格診断と同じ形式で、**説明も一言でついてくる**
- 違うのは、**観るほど中身が変わり、育っていく**こと

<!--

## おすすめには「理由」がつく

- 出すのは 3 つ：**あなたの予想評価 / 相性の数字 / どれくらい自信があるか**
- そこに一言の理由を足す：
  **「あなたが 4.5 をつけた〇〇に近い作品です」**
- 世間の平均点は**参考程度**にしか使わない

**配信サービスの「一致度 ○%」に、「なぜ」を足したものです。**

## デモ：星をつけると画面が変わる

1. 最初の数本に星をつける → **タイプと図が生まれる**
2. おすすめ画面で **相性の数字と理由**を見る
3. もう一本評価する → **タイプとおすすめが変わる**
4. 棚に追加 → **自分の映画棚が増える**

## Supabase：データの置き場所として使用

- 評価・棚・タイプ・感想など**ユーザーのデータは全部 Supabase に保存**
- 手元では軽い置き場所、本番は Supabase に**設定 1 行で切り替わる**
- 全 15 種類のデータを同じ形のまま本番へ反映でき、共同視聴の反応は Supabase の即時通知で届く

**「動くところまで持っていく」速度を Supabase が担保した。**

<!--
35秒。スポンサー配点の前半。「保存先」という言い方で通す。

## Devin：仕様書を渡して実装してもらった

- 企画書を渡すだけで **アプリの実装（約 7,500 行）をほぼ全量 Devin が作成**
- 好みの計算・おすすめ・画面・スマホ対応まで、会話しながら作り込み
- **チャットで指示 → 差分を確認**の流れで 29 回に分けて追加（この資料も README も Devin 作）

**人は「何を作るか」だけを考え、実装は Devin に任せた。**

## 新しさ：「作品」ではなく「あなた」が主役

- 既存のサービスは作品を並べる。こちらは**あなたを描く**
- 一度で終わる診断と、理由が見えないおすすめの**間を埋めた**
- 好みを言葉にできたので、**おすすめも共有も同じ説明でつながる**
